1. Which extensions did you install? Why?
### React Developer Tools
- Used to inspect React components in a web application.
- Allows developers to view the component hierarchy, inspect props and state, and debug React applications more efficiently.

### Redux DevTools
- Used to inspect and debug Redux state management.
- Makes it easy to view dispatched actions, track state changes, and troubleshoot application logic.

### JSON Viewer (or JSON Formatter)
- Used to display JSON responses in a readable, formatted structure.
- Makes API responses easier to understand by allowing objects and arrays to be expanded and collapsed.

### Lighthouse
- Used to audit the quality of web applications.
- Provides reports on performance, accessibility, SEO, and best practices, helping identify areas for improvement.

2. What was the most useful thing you learned?
- The most useful thing I learned was how Chrome DevTools extensions can simplify web development and debugging. React Developer Tools makes it much easier to inspect components and their state, while Redux DevTools helps track application state changes. I also learned that Lighthouse is built into Chrome DevTools and can generate performance and accessibility reports for websites served over HTTP or HTTPS, including local development servers such as `http://localhost`.
