# When to Use Google, AI Tools, or Ask for Help?

## Best Practices for Troubleshooting Coding Problems

A good troubleshooting process starts by reading the error message carefully,
reproducing the problem, and breaking the issue into smaller parts.

Useful techniques include checking variable values with print statements or a
debugger, reviewing recent code changes, testing one section at a time,
searching official documentation, and writing small test cases to confirm
assumptions.

It is also helpful to restart the environment when hidden state or
configuration issues may be involved.

## Using AI in Coding

AI tools such as ChatGPT can be very helpful when learning or troubleshooting
code.

They can explain error messages, suggest debugging steps, provide example code,
help refactor messy code, and explain unfamiliar programming concepts in
simpler language.

AI is especially useful when I need ideas quickly or want a second perspective
on a problem.

However, AI should not be relied on completely. It can sometimes produce
incorrect, outdated, or insecure code, and it may misunderstand the context of
a project.

Developers should always test AI-generated code, check official documentation
when accuracy matters, and make sure they understand the solution before using
it.

## Decision-Making Framework

I created a flowchart in Miro to decide when to use Google, AI tools, or ask a
colleague for help.

The flowchart considers:

- The complexity of the problem.
- The sensitivity of the information.
- The urgency of the task.

For general documentation, known error messages, and reliable technical
sources, Google is useful.

For explanations, brainstorming, debugging guidance, and step-by-step support,
AI tools can be helpful.

For project-specific problems, sensitive information, urgent issues, or
situations where online resources have not solved the problem, asking a
colleague is more appropriate.

## Reflection

### When do you prefer using AI vs. searching Google?

I prefer using AI when I need a quick explanation, help understanding code, or
step-by-step guidance for solving a problem.

I prefer Google when I need official documentation, information about a
specific error message, or reliable sources that I can verify.

I find that using both together is useful because AI can help me understand the
problem, while Google can help me verify the information.

### How do you decide when to ask a colleague instead?

I would ask a colleague when the problem is specific to the project, involves
sensitive information, or requires knowledge that may not be available online.

I would also ask for help if I have already tried Google, AI tools, and
debugging techniques but still cannot solve the problem.

For urgent issues, asking an experienced colleague can also be the quickest and
safest option.

### What challenges do developers face when troubleshooting alone?

Developers troubleshooting alone can struggle to identify the cause of a
problem, especially when they have been looking at the same code for a long
time.

They may overlook simple mistakes, misunderstand error messages, or spend too
much time trying unsuccessful solutions.

Getting help from documentation, AI tools, or colleagues can provide a
different perspective and make troubleshooting faster.
