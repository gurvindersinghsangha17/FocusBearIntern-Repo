# VS Code Productivity Shortcuts

## Navigation

- `Cmd + P` - Quickly open files by searching their name.
- `Cmd + Shift + O` - Navigate to symbols/functions in the current file.
- `Cmd + G` - Go to a specific line number.

## Editing

- `Cmd + D` - Select the next matching word (useful for multiple edits).
- `Option + Click` - Add multiple cursors (multiple cursors are very useful for editing multiple lines at once).
- `Shift + Option + Down` - Duplicate the current line.
- `Cmd + /` - Comment or uncomment selected lines.

## Debugging

- `F5` - Start debugging.
- `F9` - Add or remove a breakpoint.

## Terminal Commands

- `Control + `` ` - Open or close the integrated terminal.
- `Cmd + K` then `Cmd + S` - Open keyboard shortcuts settings.

# Reflection

The shortcuts I think will be most useful in my daily work are multiple cursors, quick file search, and commenting code. Multiple cursors will allow me to make changes faster across multiple lines, while file search helps me navigate large projects more efficiently.

Keyboard shortcuts improve productivity by reducing the time spent searching through menus and using the mouse. They allow developers to focus more on writing and reviewing code, making the workflow faster and more efficient.
